# 🏛️ Modelo de PDTI Higienizado para Prefeituras

Bem-vindo(a) ao repositório do **Modelo de Plano Diretor de Tecnologia da Informação (PDTI)** voltado para a administração pública municipal. 

O objetivo deste projeto é fornecer um esqueleto prático, higienizado e estruturado para ajudar prefeituras (especialmente as de pequeno e médio porte) a organizarem sua governança de TI, segurança da informação e conformidade com a LGPD.

## 🚀 Como usar este modelo?
1. Copie o texto Markdown abaixo ou baixe o arquivo editável disponível neste repositório.
2. Substitua todos os campos marcados com `[TAGS]` (como `[NOME_DO_MUNICIPIO]`) pelas informações reais da sua cidade.
3. Adapte os quantitativos e metas de acordo com o orçamento disponível no seu município.
